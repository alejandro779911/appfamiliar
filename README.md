# Gastos Familiares

Mini aplicación web para llevar el control de los gastos mensuales de la familia. No requiere backend ni instalación: funciona directamente en el navegador y guarda los datos en `localStorage`.

## Funcionalidades

- Registrar gastos con descripción, monto, categoría, miembro de la familia y fecha.
- Navegar entre meses (anterior/siguiente).
- Definir un presupuesto mensual y ver cuánto queda disponible.
- Ver el desglose de gastos por categoría con barras de proporción.
- Filtrar el historial por categoría o miembro.
- Exportar los gastos del mes a CSV.
- Borrar los gastos de un mes completo.

## Uso

Abre `index.html` en tu navegador (doble clic o `open index.html`). No necesita servidor ni dependencias.

Los datos se guardan localmente en el navegador (localStorage), por lo que persisten entre sesiones en el mismo dispositivo y navegador.
